# PPP (Projeto Político-Pedagógico)

## Visão geral
O módulo PPP reutiliza o mesmo modelo de trilhas (Tarefa/Pergunta/Resposta) para organizar a escrita do Projeto Político-Pedagógico.

## Como funciona
- O PPP é apresentado em **/ppp**.
- Cada trilha PPP é uma Tarefa já existente.
- Os blocos do PPP são as Perguntas associadas à tarefa.
- O texto é produzido nas respostas (Respostas) e acompanhado por pareceres (Revisões).

## Configuração (Admin)
1. Acesse **/admin/ppp**.
2. Selecione as trilhas que compõem o PPP.
3. Salve a configuração.

## Escopo
- O PPP é municipal (escopo por cliente).
- Não há entidade Escola no banco atual; quando houver, a filtragem poderá ser estendida.

## Reuso de textos
- Textos dos Cadernos podem ser vinculados a perguntas do PPP para reutilização.
