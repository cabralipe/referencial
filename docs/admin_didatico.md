# Admin Console Didático

Este guia explica como usar o Admin Console remodelado para equipes não técnicas.

## 1) Comece por aqui
Ao abrir **/admin/console**, você verá:
- **Atalhos rápidos** para as ações mais comuns.
- **Checklist de configuração mínima** (o que falta para começar).
- **Ajuda rápida** com boas práticas.

## 2) Atalhos principais
- **Criar GT**: monte os grupos de trabalho.
- **Criar tarefa**: defina trilhas/etapas.
- **Criar pergunta**: configure os blocos de escrita.
- **Revisões pendentes**: acompanhe o que está em análise.
- **Publicar mural**: avisos para os GTs.
- **Exportar documento**: gere relatórios finais.

## 3) Módulos com linguagem humana
Cada módulo mostra:
- Nome simples
- Descrição clara
- Exemplos
- Tags (ex.: “comece-aqui”, “currículo”)

## 4) Modo simples vs avançado
Dentro de um módulo:
- **Modo simples (padrão)**: mostra apenas colunas e campos essenciais.
- **Modo avançado**: libera todos os campos + editor JSON.

## 5) Filtros rápidos
Alguns módulos possuem filtros de 1 clique:
- Revisões: pendentes, devolvidas, validadas.
- Usuários: ativos, bloqueados.
- Trilhas: ativas, concluídas.

## 6) Dica para equipes
Sugestão de sequência:
1. Usuários
2. GTs
3. Trilhas
4. Perguntas
5. Mural
