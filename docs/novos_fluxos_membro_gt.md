# Novos Fluxos do Membro GT

Este guia explica o novo passo a passo para o Membro GT na Plataforma MEB Referencial.

## 1) Acesso inicial
1. Faça login normalmente.
2. Você será direcionado para **/inicio** com um resumo das trilhas e pareceres.

## 2) Minha Trilha
1. Acesse **/minha-trilha**.
2. Escolha o seu GT (se houver mais de um).
3. Veja a lista de trilhas, status e progresso.
4. Clique em **Abrir trilha** para seguir os blocos.

## 3) Blocos da Trilha
1. Cada trilha tem missões em sequência.
2. O status indica se o bloco está em andamento, em revisão, devolvido ou concluído.
3. Clique em **Abrir texto** para editar a resposta do bloco.

## 4) Construção de Texto
1. Acesse **/texto** para listar os textos do seu GT.
2. Abra o texto desejado em **/texto/:id**.
3. Use as ferramentas de inserção (título, lista, tabela, BNCC).
4. Registre comentários por trecho quando necessário.
5. Use o histórico de versões para comparar mudanças.

## 5) Cadernos
1. Acesse **/cadernos**.
2. Crie um novo caderno com um texto inicial.
3. Dentro de **/cadernos/:id**, adicione textos e vincule a perguntas.

## 6) Mural
1. Abra **/mural** para ver avisos publicados pela administração.
2. Avisos fixados aparecem no topo.

## 7) PPP
1. Acesse **/ppp**.
2. Selecione a trilha do PPP e avance pelos blocos.

## 8) Ajuda
1. Em **/ajuda**, consulte orientações rápidas.
2. Use o chat do MEB para dúvidas específicas.
